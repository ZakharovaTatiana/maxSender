# Фокус и очистка поля номера

## Цель и границы

Исправить визуальное состояние фокуса в форме добавления номера и автоматически очищать выбранный номер через три секунды после успешной проверки аккаунта. Контракт API, список чатов и правила валидации номера не менять.

## Наблюдаемое и ожидаемое поведение

Сейчас синее focus-кольцо поля и списка кода страны выходит за внешние границы составного блока. После успешного поиска значение номера остаётся в поле.

После изменения focus-кольцо располагается внутри границ активного блока и проходит по его периметру. После успешного ответа `checkAccount` введённый национальный номер очищается через 3 секунды. Если до срабатывания таймера пользователь изменил номер или код страны, новое значение не очищается.

## Текущая реализация

- [`ContactSearchForm`](../../src/features/contact-search/ui/ContactSearchForm.tsx) хранит код страны и номер в локальном состоянии.
- Список кода страны и поле номера используют внешнее `focus:ring-2`.
- Успешный `checkAccount` добавляет новый чат либо завершает обработку, если чат уже существует.

## Решение

- Использовать inset-вариант focus-ring для select и input, сохранив видимый двухпиксельный контур внутри блока.
- После любого успешного `checkAccount`, включая уже добавленный чат, запускать трёхсекундный таймер очистки.
- Перед новым таймером отменять предыдущий. При ручном изменении или вставке нового значения отменять ожидающую очистку; при размонтировании формы очищать таймер.

## Этапы и затрагиваемые файлы

1. Обновить focus-стили и управление таймером в `src/features/contact-search/ui/ContactSearchForm.tsx`.
2. Выполнить автоматические проверки.
3. Зафиксировать результат в `status.md` и `implementation.md`.

## Приватность и безопасность

Номер не логируется и не сохраняется новым способом. Автоматическая очистка уменьшает время его отображения в поле после выбора. API-запросы и хранение сессии не меняются.

## Риски и критерии приёмки

Focus-кольцо не выступает за границы блока. Успешно выбранный номер исчезает через 3 секунды. Ошибка поиска сохраняет номер для исправления. Ручной ввод нового значения до истечения таймера не теряется. Таймер не обновляет размонтированный компонент.
