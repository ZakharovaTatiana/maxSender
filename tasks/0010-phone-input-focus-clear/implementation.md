# Реализация фокуса и очистки поля номера

## Итоговое поведение

При фокусе на коде страны или поле номера синяя двухпиксельная обводка отображается внутри соответствующего сегмента формы и не выступает за его границы.

После успешного ответа проверки аккаунта национальная часть номера остаётся видимой ещё 3 секунды, затем очищается. Это поведение применяется как к новому, так и к ранее добавленному чату. При ошибке поиска номер не очищается. Если пользователь начинает вводить или вставляет другое значение либо меняет код страны, ожидающая очистка отменяется.

Реализация принята пользователем 2026-09-28.

## Ключевые изменения

- К focus-ring элементов добавлен `ring-inset`.
- В `ContactSearchForm` добавлен управляемый timeout очистки номера.
- Перед повторным запуском, при ручном изменении формы и при размонтировании timeout отменяется.
- Перед очисткой проверяется, что поле всё ещё содержит успешно отправленное значение.

Маршруты, Redux-state, API, валидация и зависимости не изменены.
