# Реализация предупреждения на странице авторизации

## Итоговое поведение

Под кнопкой «Войти» отображается красный информационный блок с иконкой восклицательного знака. Блок сообщает, что из-за тестового характера проекта данные авторизации хранятся в `localStorage` браузера и передаются только в запросах к GREEN-API.

Реализация принята пользователем 2026-09-28.

## Ключевые изменения

- В `LoginForm` добавлен статический блок `role="note"`.
- Иконка реализована встроенным SVG и не требует новой зависимости.
- Маршруты, Redux-состояние, механизм сохранения сессии, API-запросы и конфигурация не изменены.

## Ограничения и технический долг

Блок информирует пользователя, но не изменяет существующую модель хранения данных. Дополнительных ограничений и технического долга не добавлено.

## Проверка

- `npm run build` — успешно.
- `npm run lint` — успешно.
- `npm run format:check` — успешно.
- `git diff --check` — успешно.
- Браузерные smoke checks не выполнялись согласно инструкции проекта.

## Поставка и откат

Отдельные действия для поставки не требуются. Для отката достаточно удалить информационный блок из `LoginForm` и каталог этой задачи.
