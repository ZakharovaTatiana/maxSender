# Реализация

## Итоговое поведение

Клик по чату делает его единственным активным и открывает справа детализацию. Заголовок содержит кнопку назад, аватар и имя из списка. Кнопка назад снимает активность. Выбор другого чата сразу переключает детализацию.

При первом открытии чата выполняется `GetChatHistory`. В запрос передаётся только `chatId`, поэтому используется стандартный лимит API — 100 сообщений. Для каждого чата выполняется только одна попытка загрузки; повторные открытия не обращаются к API снова.

Поскольку серверный фильтр по типу сообщения отсутствует, ответ фильтруется на клиенте до сохранения в Redux. В `messages` попадают только `textMessage` и `extendedTextMessage`; медиа, реакции, опросы и другие типы отбрасываются вместе с их полями. Сохраняются общие поля сообщения, текст и относящиеся к направлению метаданные.

Сообщения сортируются по времени от старых к новым. Входящие отображаются слева, исходящие — справа. История группируется по локальной календарной дате: текущий день подписывается «сегодня», предыдущий — «вчера», остальные — датой вида «03 сентября 2026 г.». В пузыре отображаются текст и время сообщения.

Авторизованный экран ограничен высотой окна. При переполнении прокручивается центральная область истории, а заголовок чата и форма сообщения остаются на месте; после первой загрузки история прокручивается к последнему сообщению.

Внизу находится растущее вместе с текстом поле. `Enter` и кнопка со стрелкой временно выводят непустой текст в консоль и очищают поле; `Shift+Enter` добавляет перенос строки. Реальная отправка сообщений пока не подключена.

## Ключевые изменения

- В объект чата добавлены `messages` и состояние единственной попытки загрузки истории.
- В feature `chat-history` добавлены запрос, фильтрация ответа и сценарий первого открытия.
- В детализацию добавлены состояния загрузки, пустой истории и ошибки, группы дат и пузыри сообщений.
- Общие имя и аватар чата переиспользуются в списке и заголовке.
- В общем описании проекта зафиксирована поддержка только текстовых сообщений.

## Состояние, маршруты и зависимости

Каждый объект чата содержит массив `messages` и `historyStatus`: `idle`, `loading`, `loaded` или `failed`. Статус меняется с `idle` при первой попытке и больше не возвращается в него, поэтому повторного запроса нет. Маршруты и зависимости проекта не изменялись.

## Ограничения

- История ограничена стандартными 100 сообщениями и не обновляется после первой попытки.
- Повторная загрузка после ошибки не предусмотрена.
- Нетекстовые сообщения не сохраняются и не отображаются.
- Реальная отправка сообщений не реализована; текст временно выводится в консоль.
