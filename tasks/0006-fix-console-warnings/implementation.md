# Bug fix: предупреждения консоли

Результат принят пользователем 2026-09-26.

`selectChats` мемоизирован через Redux Toolkit `createSelector`. Повторные обращения при неизменной ветке chats возвращают тот же массив, включая изменения других веток состояния. При изменении чатов результат пересчитывается; сортировка по order сохраняется. Это устраняет причину предупреждения React Redux.

В BrowserRouter включены `v7_startTransition` и `v7_relativeSplatPath`, устраняющие два предупреждения о будущих изменениях React Router. Набор маршрутов, структура Redux, зависимости и API не изменены. Информационное приглашение установить React DevTools сохранено.
