# Реализация мобильного интерфейса чатов

## Итоговое поведение

На экранах уже `lg` авторизованный интерфейс работает как два полноэкранных состояния. По умолчанию отображаются заголовок «Чаты» с кнопкой выхода, форма добавления номера и список ранее добавленных чатов. После выбора чата список скрывается и отображается активный чат; стрелка в его заголовке возвращает пользователя к списку.

На ширине `lg` и больше сохраняется desktop-компоновка с боковой панелью, списком и областью активного чата.

Реализация принята пользователем 2026-09-28.

## Ключевые изменения

- Добавлена feature `logout` с вариантами кнопки для боковой панели и мобильного заголовка.
- `NavigationSidebar` скрывается на мобильных экранах.
- `ChatPanel` использует существующий `selectActiveChat` для мобильной видимости и содержит мобильную кнопку выхода.
- Пустая область `ChatDetails` скрывается на мобильном экране, а активный чат остаётся полноширинным.
- Авторизованная страница использует `100dvh` с fallback на `100vh` для корректной высоты в мобильных браузерах.

Маршруты, Redux-state, API и зависимости не изменены.

## Ограничения и технический долг

Breakpoint мобильного режима совпадает со стандартным Tailwind `lg` (1024 px): мобильная компоновка действует на ширинах меньше 1024 px. Визуальная проверка в браузере не выполнялась по инструкции проекта и остаётся частью пользовательской приёмки.
