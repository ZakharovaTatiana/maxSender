# Мобильный интерфейс чатов

## Цель и границы

Адаптировать авторизованную часть приложения для мобильных экранов по предоставленным визуальным референсам. На мобильной ширине список чатов и открытый чат должны быть отдельными состояниями интерфейса. Desktop-компоновку и бизнес-логику чатов не менять.

## Наблюдаемое и ожидаемое поведение

Сейчас `NavigationSidebar`, `ChatPanel` и `ChatDetails` находятся рядом во flex-контейнере даже на узком экране. После изменения до breakpoint `lg`:

- без активного чата виден полноширинный список: заголовок и кнопка выхода наверху, форма добавления номера ниже, затем ранее добавленные чаты;
- при выборе чата список и кнопка выхода скрываются, а чат занимает весь экран;
- стрелка в заголовке активного чата закрывает его и возвращает к списку.

Начиная с `lg`, сохраняется существующий desktop-интерфейс с боковой панелью, списком и деталями.

## Текущая реализация

- [`MainPage`](../../src/pages/main/ui/MainPage.tsx) выводит три соседних компонента для авторизованного пользователя.
- [`NavigationSidebar`](../../src/widgets/navigation-sidebar/ui/NavigationSidebar.tsx) содержит кнопку выхода.
- [`ChatPanel`](../../src/widgets/chat-panel/ui/ChatPanel.tsx) содержит заголовок, форму поиска и список чатов.
- [`ChatDetails`](../../src/widgets/chat-details/ui/ChatDetails.tsx) уже деактивирует чат по кнопке со стрелкой.

## Решение

- Управлять мобильной видимостью списка и деталей через существующий `selectActiveChat`, не добавляя новое состояние.
- Скрыть боковую навигацию на мобильной ширине.
- Вынести действие выхода в feature `logout`, чтобы переиспользовать его в боковой панели и мобильном заголовке без импорта между widgets одного слоя.
- Сохранить DOM-компоненты смонтированными на desktop и использовать responsive-классы Tailwind для переключения мобильных экранов.

## Этапы и затрагиваемые файлы

1. Добавить `src/features/logout` с переиспользуемой кнопкой выхода.
2. Обновить `NavigationSidebar`, `ChatPanel` и `ChatDetails` для адаптивной компоновки.
3. Выполнить автоматические проверки и оформить итоговую документацию.

## Приватность и безопасность

Обработка данных авторизации и сообщений не меняется. Кнопка выхода использует существующее действие `clearCredentials`, которое очищает сессию.

## Риски и критерии приёмки

На ширине меньше 1024 px одновременно виден только список или открытый чат; чат занимает доступную ширину и высоту; стрелка возвращает к списку; выход расположен справа вверху списка; форма поиска находится над списком. На desktop регрессии компоновки отсутствуют.
