# Реализация

## Итоговое поведение

На главной странице неавторизованному пользователю показывается центрированная форма входа в визуальном стиле `web.max.ru`. После отправки `idInstance`, `apiTokenInstance` и `apiUrl` сохраняются в Redux state; три непустых значения означают авторизованное состояние. Авторизованному пользователю показываются левая панель управления и заготовка панели чатов на общем фоне приложения.

## Ключевые изменения

- Добавлена Redux-модель с пустыми `idInstance`, `apiTokenInstance` и `apiUrl` в исходном состоянии.
- Форма входа вынесена в FSD-слой `features`.
- Поле `idInstance` очищает все символы, кроме цифр.
- Токен скрыт по умолчанию и записывается в Redux state только после отправки формы.
- Поле `apiUrl` предзаполнено адресом `https://3100.api.green-api.com` и проверяет формат HTTP/HTTPS URL.
- Авторизация вычисляется по наличию трёх непустых параметров в state.
- Кнопка входа отключена, пока три поля не заполнены корректными значениями.
- Фоновый узор и градиент перенесены с визуального референса `web.max.ru`; ресурс хранится локально в проекте.
- Убрана декоративная иконка перед заголовком формы.
- Добавлена левая панель с закреплённой внизу кнопкой «Выход»; другие кнопки управления пока отсутствуют.
- Кнопка «Выход» очищает три параметра сессии и возвращает пользователя к форме входа.
- Добавлена панель «Чаты» с полем «Найти по номеру телефона»; список чатов пока не реализован.
- Авторизованное и неавторизованное состояния используют один фоновый компонент.
- Маршруты и зависимости не изменены.

## Ограничения и технический долг

- Подключение API авторизации отсутствует; значения не проверяются на сервере.
- Состояние хранится только в памяти и очищается после перезагрузки страницы.
- Токен доступен инструментам, имеющим доступ к Redux state, включая Redux DevTools при их подключении.
- Поиск и список чатов пока не подключены к данным и маршрутам.

## Проверка

- `npm run build` — успешно.
- `npm run lint` — успешно.
- `npm run format:check` — успешно.
- `git diff --check` — успешно.
- Ручной smoke test — `apiUrl` предзаполнен, неверный URL блокирует вход, корректный URL позволяет сохранить три параметра; выход очищает сессию и возвращает форму авторизации.
