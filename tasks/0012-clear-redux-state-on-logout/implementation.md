# Реализация очистки Redux state при выходе

## Итоговое поведение

Действие `clearCredentials`, отправляемое кнопкой выхода, теперь сбрасывает корневой Redux state. Session возвращается к пустым параметрам, а chats — к пустому объекту. Добавленные чаты, активный чат, сообщения и статусы загрузки больше не остаются в памяти после logout.

Подписка store продолжает отслеживать изменение сессии и после reset запускает очистку `localStorage`, реализованную в задаче `0011`.

Реализация принята пользователем 2026-09-28.

## Ключевые изменения

- Slice reducers собраны через `combineReducers`.
- Добавлен `appReducer`, который распознаёт `clearCredentials` и передаёт root reducer состояние `undefined`.
- Начальное состояние для preload создаётся root reducer, после чего при наличии сохранённой сессии заменяется только session slice.

Маршруты, компоненты, API и зависимости не изменены.

## Ограничения и технический долг

Root reset привязан к существующему действию `clearCredentials`; любой будущий вызов этого действия также очистит весь state, что соответствует его роли logout. Браузерная проверка не выполнялась согласно инструкции проекта.
