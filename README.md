# MaxSender

## Локальный запуск

Для запуска проекта требуются:

- Node.js 22.12 или новее;
- npm.

Установите зависимости из `package-lock.json`:

```sh
npm ci
```

Запустите сервер разработки:

```sh
npm run dev
```

После запуска откройте адрес, указанный Vite в терминале. По умолчанию приложение доступно по адресу [http://localhost:5173](http://localhost:5173).

Backend, база данных и контейнеры для локального запуска не требуются.
