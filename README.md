# MaxSender

Фронтенд на React 19, TypeScript, Vite 7, Redux Toolkit, React Router 6 и Tailwind CSS 4.

Приложение работает только с текстовыми сообщениями. Если метод API поддерживает фильтрацию по типу сообщения, запрос должен ограничиваться текстовыми сообщениями. Если серверная фильтрация недоступна, ответ нужно отфильтровать до сохранения в состоянии приложения и оставить только текстовые сообщения и относящиеся к ним поля.

## Запуск

Требуется Node.js 22.12+ и npm. Контейнеры и серверная часть не нужны.

```sh
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite (по умолчанию http://localhost:5173).

## Команды

- `npm run build` — проверка TypeScript и production-сборка в `dist`.
- `npm run preview` — локальный просмотр сборки.
- `npm run typecheck` — проверка типов приложения и конфигурации Vite.
- `npm run lint` — ESLint с правилами TypeScript, React Hooks и React Refresh.
- `npm run format` — форматирование Prettier.
- `npm run format:check` — проверка форматирования.

## Архитектура FSD

- `src/app` — сборка приложения, провайдеры, маршрутизация, Redux store и глобальные стили.
- `src/pages` — страницы `main` и `not-found` с публичными экспортами в `index.ts`.
- `src/widgets` — будущие самостоятельные блоки интерфейса.
- `src/features` — будущие пользовательские действия.
- `src/entities` — будущие бизнес-сущности.
- `src/shared` — общие настройки, утилиты и UI.

Импорты направлены от верхних слоёв к нижним в порядке списка выше. Слайсы одного слоя не импортируют друг друга. Используйте публичный API слайса (`index.ts`). Алиасы `@app`, `@pages`, `@widgets`, `@features`, `@entities`, `@shared` и `@` одинаково настроены в TypeScript и Vite.

Redux Provider подключён; reducers сущностей добавляются в `app/store`. Типизированные хуки находятся в `app/store/hooks.ts`; нижние слои не должны импортировать `app`, поэтому для них определяйте локальные типизированные хуки рядом с моделью.

Tailwind 4 подключён через Vite-плагин и CSS `@import 'tailwindcss'`.

Маршруты: `/` — главная, любой неизвестный адрес — 404 со ссылкой на главную. При размещении сборки настройте SPA fallback на `index.html`, чтобы прямое открытие вложенных адресов работало.
